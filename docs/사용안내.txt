충북메신저 AI 비서 v0.7.2 — 사용 안내
==========================================

충북소통메신저 쪽지와 네이버 메일을 AI(ChatGPT, 대체로 Claude)가 읽고
중요도(긴급/중요/참고)별로 요약해서 알려 주고,
일정은 바탕화면 캘린더에 '제안'으로 올려 주는 프로그램입니다.

※ 아직 시험 중인 프로그램입니다. 이상한 점이 있으면 화면을 캡처해서 알려 주세요.


■ 준비물
------------------------------------------
- Windows 10/11 PC
- ChatGPT Plus 또는 Pro 구독 (본인 계정)
- (선택) Claude Pro 또는 Max 구독 — ChatGPT 가 안 될 때 대신 쓰는 용도
- (쪽지 요약을 쓰려면) 충북소통메신저가 설치되어 로그인된 상태
- (메일 요약을 쓰려면) 네이버 메일 계정


■ 1. 설치
------------------------------------------
1) CBMessengerAI_Setup_0.7.2.exe 를 더블클릭합니다.
   - 관리자 권한, Python 등 다른 프로그램은 필요 없습니다.
   - "Windows의 PC 보호" 라는 파란 창이 뜨면
     [추가 정보] → [실행] 을 누르세요.
     (프로그램에 회사 서명이 없어서 나오는 경고입니다)
2) [다음] → [설치]
   - 원하면 "바탕화면에 아이콘 만들기", "로그인할 때 자동으로 켜기" 를 체크하세요.
3) 마지막 화면에서 "지금 ChatGPT 로그인하기" 를 체크한 채 [마침]
   → 브라우저가 열리면 본인 ChatGPT 계정으로 로그인하고 [허용]
   → 검은 창에 "로그인 완료" 가 나오면 아무 키나 눌러 닫기
   → 그 다음 캘린더가 자동으로 켜집니다.

※ ChatGPT 로그인은 꼭 본인 계정으로 하세요. (사용량이 본인 플랜에서 차감됩니다)
※ 나중에 다시 로그인하려면: 시작 메뉴 → 충북메신저 AI 비서 → ChatGPT 로그인

※ 설정 화면 여는 법 (아래에서 "설정 화면" 이라고 하면 이것입니다)
   캘린더 ⚙ → "설정 열기"
   → AI 연결 / 모델 / 저장 / 메일 / 알림 / 학교 정보 탭이 있는 창이 열립니다.
   → 고친 뒤 [저장] 을 누르면 바로 적용됩니다.
   (시작 메뉴 → 충북메신저 AI 비서 → 설정 으로도 열 수 있습니다.
    이렇게 따로 열었을 때는 저장 뒤 캘린더 ⚙ → "바꾼 설정으로 감시 다시 시작" 을 눌러 주세요)


■ 1-1. (선택) Claude 를 대체 AI 로 연결
------------------------------------------
ChatGPT 사용 한도가 차거나 로그인이 풀려서 요약이 안 될 때,
자동으로 Claude 가 대신 요약하도록 연결해 둘 수 있습니다.
Claude Pro 또는 Max 구독(본인 계정)이 있을 때만 쓸 수 있습니다.

1) 설정 화면 → [AI 연결] 탭 → "Claude 구독" 칸을 봅니다.
   - "설치돼 있지 않습니다" 로 나오면 [Claude Code 설치] 버튼을 누릅니다.
     (Claude 회사의 공식 프로그램입니다. 파란 창이 열리고 설치가 진행됩니다.
      파일이 커서 몇 분 걸리고, 그동안 멈춘 것처럼 보일 수 있습니다.)
   - "로그인이 필요합니다" 로 나오면 [Claude 로그인] 버튼을 누릅니다.
     검은 창과 브라우저가 열리면 본인 Claude 계정(Pro/Max)으로 로그인합니다.
   - 초록색 "로그인됨" 이 되면 끝입니다. (안 바뀌면 [다시 확인])
2) 설정 화면 → [모델] 탭 → "대체 모델" 칸에서 "Claude 구독" 을 고르고 [저장]
   (모델은 비워 두거나 haiku 면 충분합니다)

   버튼으로 안 될 때 직접 하는 방법:
   - 설치: 시작 버튼 → "PowerShell" 열기 → 아래 한 줄 붙여 넣고 Enter
       irm https://claude.ai/install.ps1 | iex
   - 로그인: 시작 버튼 → "cmd" 열기 → 아래를 입력하고 Enter
       %USERPROFILE%\.local\bin\claude.exe auth login

- 이 프로그램은 Claude 로그인 정보를 직접 읽지 않고, 공식 Claude Code 를 실행해서 씁니다.
  사용량은 본인 Claude 플랜에서 차감됩니다.
- 대체 모델을 쓸 수 없는 상태(설치·로그인 안 됨)면 캘린더 오른쪽 아래 상태줄에 ⚠ 경고가 뜹니다.
  설치·로그인을 마치면 프로그램을 다시 켜지 않아도 다음 번부터 자동으로 씁니다.
- Claude 는 한 건 요약에 몇 초 ~ 십수 초 걸립니다.
- 원하면 대체가 아니라 처음부터 Claude 로 쓸 수도 있습니다: [모델] 탭 "분석 모델" 을 "Claude 구독" 으로.


■ 2. 바탕화면 캘린더
------------------------------------------
- 캘린더는 모든 창의 맨 아래(바탕화면처럼)에 붙어 있습니다.
- 작업 표시줄에는 안 보이고, 시계 옆 트레이 아이콘(달력 모양)에서
  보이기 / 숨기기 / 끝내기를 할 수 있습니다.
- 이동: 맨 위 막대를 끌기 / 크기: 가장자리나 오른쪽 아래 모서리를 끌기
- 오른쪽 [받은 소식] 탭: 쪽지·메일을 중요도순으로 보여 줍니다.
  눌러 보면 요약 · 할 일 · 원문을 볼 수 있고, [✓ 처리 완료] 로 정리합니다.
- AI가 찾은 일정은 점선(제안)으로 올라옵니다. 눌러서 [확정] 또는 [무시].
  (AI가 날짜를 잘못 읽을 수 있어서 바로 넣지 않고 확인을 받습니다)
- ⚙ 버튼: 위치·크기, 밝은/어두운 테마, 투명도, AI 모델 고르기, 설정 열기, 업데이트,
  다른 캘린더에서 일정 가져오기, 확정 일정 내보내기

■ 메모 (캡처를 붙여 넣으면 AI 가 정리)
------------------------------------------
1) 캘린더 오른쪽 [메모] 탭 → 점선 상자를 한 번 누르고 Ctrl+V (캡처: Win+Shift+S).
   [이미지 고르기]·끌어다 놓기·글 붙여 넣기도 됩니다.
2) 읽는 방식: '이 PC 에서 글자만 읽기'(권장 — 개인정보를 가리고 AI 로 보냄) 또는
   '캡처를 AI 에 그대로 보내기'(표·그림 이해가 낫지만 이름·전화번호가 그대로 감).
3) 읽은 글자에서 틀린 곳을 고치고 [AI로 정리하기] (수십 초).
4) 메모에서 종류를 바꾸고 [다시 정리], 날짜가 있으면 일정 '제안', 없으면 [일정으로 넣기].
- 캡처는 이 PC 의 data\메모 폴더에 남습니다. 메모를 지워도 그 메모로 만든 일정은 남습니다.
- 설정 화면에서 메모 기능을 끌 수 있습니다 (끄면 메모 탭이 사라짐).

■ 내가 보낸 쪽지가 분석될 때
------------------------------------------
설정 화면 → [학교 정보] 탭 → '메신저에 표시되는 내 이름' 에 메신저에 보이는 내 이름을 적고 [저장].
보낸 사람이 그 이름과 똑같은 쪽지는 저장·AI 분석·알림을 하지 않습니다. ('나에게 쓰기'로 시험할 때는 잠시 비워 두세요)

■ 받은 소식 자세히 보기
------------------------------------------
- 받은 소식에서 쪽지·메일을 누르면 AI 요약 아래에 '자세히' 정리(무엇·언제·어디·대상·제출물·문의)가 나옵니다.
- 예전에 분석한 것은 '자세히'가 없을 수 있습니다. [다시 분석] 을 누르면 지금 AI 설정으로 다시 정리합니다 (수십 초).
- 아래 '캘린더 일정' 을 누르면 그 일정으로 바로 갑니다.
- 반대로 달력에서 AI 가 만든 일정을 누르면 원래 쪽지가 보이고, [원문 자세히 보기 ›] 로 받은 소식 화면으로 갈 수 있습니다.

■ 다른 캘린더의 일정 한꺼번에 넣기
------------------------------------------
⚙ → "다른 캘린더에서 일정 가져오기" → 파일 고르기
- 넣을 수 있는 파일
  · .ics : 구글·네이버·Outlook 캘린더에서 '내보내기' 한 파일
  · 엑셀(.xlsx) / .csv : 날짜·제목(행사명)·시간·장소 칸이 있는 표,
    또는 학교 연간 계획 같은 '주간 달력' 모양 (맨 왼쪽에 2026.11, 칸 안 첫 줄이 날짜 숫자)
  · .txt : 한 줄에 일정 하나  예) 2026-11-12 14:00 학년 협의회
           또는 '11월 25일(화)' 줄 아래에 '- 9:00 교직원 회의' 같은 줄들
  · 옛 엑셀(.xls)은 엑셀에서 '다른 이름으로 저장 → Excel 통합 문서(.xlsx)' 로 바꿔서 넣으세요.
- 넣기 전에 미리보기 표가 나옵니다. 빼고 싶은 일정은 체크를 풀고 [선택한 ○건 넣기].
  표에서 날짜·제목 칸을 잘못 알아봤으면 위쪽 '칸 맞추기' 에서 바꿀 수 있습니다.
- 이미 캘린더에 있는 일정(같은 날짜·제목·시각)은 자동으로 빼 둡니다. 같은 파일을 두 번 넣어도 두 번 들어가지 않습니다.
- 잘못 넣었으면 ⚙ → "마지막 가져오기 되돌리기" 로 방금 넣은 일정만 지울 수 있습니다.
- 파일 내용은 이 PC 안에서만 읽고, AI 나 인터넷으로 보내지 않습니다.


■ 3. 네이버 메일 연결 (선택)
------------------------------------------
1) 네이버 메일 → 환경설정 → POP3/IMAP 설정 → "IMAP/SMTP 사용함" 저장
2) 네이버 2단계 인증을 켜고 "애플리케이션 비밀번호" 를 발급받습니다.
   (평소 로그인 비밀번호가 아니라, 이때 받은 비밀번호를 씁니다)
3) 설정 화면 → [메일] 탭에 네이버 주소와 애플리케이션 비밀번호 입력
   → [연결 확인 후 비밀번호 저장]
4) 캘린더 ⚙ → "바꾼 설정으로 감시 다시 시작"

- 메일은 읽기만 합니다 (읽음 표시·삭제·보내기를 하지 않음).
- 비밀번호는 Windows 자격 증명 관리자에만 저장됩니다.


■ 4. 소통메신저 쪽지
------------------------------------------
- 소통메신저에 로그인해 두면, 새 쪽지 알림 창이 뜰 때 내용을 읽어 요약합니다.
  (메신저 창의 글자를 읽기만 하고, 클릭·답장은 하지 않습니다)
- 잘 읽히는지 확인: 쪽지 하나를 열어 둔 채
  시작 메뉴 → 충북메신저 AI 비서 → "쪽지 창 읽기 확인"
- 보안 쪽지는 내용을 저장하거나 AI로 보내지 않습니다.


■ 5. 알림
------------------------------------------
- 기본: "학교 업무" 로 판단된 것만, 내용은 숨긴 채 알림 (옆 사람이 볼 수 있으니까요)
- 밤 10시 ~ 아침 8시는 알림을 보내지 않습니다.
- 바꾸려면: 설정 화면 → [알림] 탭 → 저장 → 캘린더 ⚙ → "바꾼 설정으로 감시 다시 시작"


■ 6. 업데이트
------------------------------------------
- 새 버전이 나오면 ⚙ 버튼에 점이 생깁니다.
- ⚙ → "⬆ 새 버전 … 설치하기" → [설치] → 잠시 꺼졌다가 다시 켜집니다.
  (일정·설정·기록은 그대로 남습니다)


■ 7. 지우기
------------------------------------------
- Windows 설정 → 앱 → "충북메신저 AI 비서" → 제거
- 설정과 기록은 아래 폴더에 남습니다. 완전히 지우려면 이 폴더도 지우세요.
  %LOCALAPPDATA%\cb-messenger-ai
  (파일 탐색기 주소창에 위 글자를 그대로 붙여 넣으면 열립니다)


■ ⚠ 꼭 알아 두세요 (개인정보)
------------------------------------------
- 쪽지·메일 내용이 요약을 위해 OpenAI(ChatGPT) 서버로 전송됩니다.
  Claude 를 연결했다면 Anthropic(Claude) 서버로도 전송될 수 있습니다.
  전화번호·주민번호·이메일·학번 등은 자동으로 가린 뒤 보내지만,
  학생 이름은 자동으로 못 가립니다.
  → 가리고 싶은 이름은 메모장으로 아래 설정 파일을 열어
     REDACT_NAMES= 줄 뒤에 쉼표로 적고 저장한 뒤 (예: REDACT_NAMES=홍길동,김철수)
     ⚙ → "바꾼 설정으로 감시 다시 시작" 을 누르세요.
     %LOCALAPPDATA%\cb-messenger-ai\.env
- 학교 업무용으로 쓰기 전에 학교(교육청) 정보보안 담당자에게
  외부 AI 사용이 괜찮은지 먼저 확인하는 것을 권합니다.
- 원문과 요약은 이 PC 안에만 저장됩니다.


■ 문제가 생기면
------------------------------------------
- 캘린더가 안 켜질 때: %LOCALAPPDATA%\cb-messenger-ai\data\calendar.log 파일을 보내 주세요.
  (쪽지 본문은 들어 있지 않지만 보낸 사람 이름이 적혀 있을 수 있으니, 보내기 전에 열어서 확인하세요)
- 그 밖에는 오류 화면을 캡처해서 보내 주세요.
