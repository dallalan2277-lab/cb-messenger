# 공통 작업 규칙 (모든 프로젝트 · Codex)

## 사용자
- 비개발자 교사. 설명은 **한국어로, 쉬운 말로**, 전문 용어는 풀어서. 끝나면 무엇을 바꿨는지 짧게 알려 준다.
- 결과물은 더블클릭으로 쓸 수 있게. 명령을 쳐야 하면 한 단계씩 안내한다.
- 프로젝트 폴더의 `AGENTS.md`·`CLAUDE.md`에 다른 규칙이 있으면 그쪽을 따른다.

## 지켜야 할 것
- 학생 정보, 쪽지·메일 원문, 비밀번호·토큰·비밀 키는 커밋·로그·출력에 남기지 않는다. 테스트에는 가상 예시만 쓴다.
- commit·push는 사용자가 요청할 때만 한다. 되돌리기 어려운 일(삭제, 배포, 외부로 보내기)은 먼저 묻는다.

## 사용량 아끼기 (ChatGPT Plus 한도)
2026-11-11 분석: 한도를 가장 많이 쓰는 것은 **호출마다 다시 읽는 대화 길이**다(대화 하나가 사흘치 사용량의 65%).
보조 에이전트는 부모 대화를 통째로 복사하고 시작해서 사용량의 43%를 썼다.
- 보조 에이전트(spawn_agent)는 쓰지 않는다. 꼭 필요하면 1~2개만, 짧은 지시로 시작시키고, 기다리기·상태 확인을 되풀이하지 않는다.
- 파일은 필요한 부분만 읽고, 명령 출력은 필요한 줄만 남긴다(긴 로그·전체 파일 출력 금지). 이미 읽은 파일·폴더 목록은 다시 읽지 않는다.
- 테스트·빌드는 고친 부분에 맞는 것만 돌리고, 전체 테스트·빌드는 마지막에 한 번만.
- 요청 범위 밖의 정리·재검증은 하지 말고 제안만 한다.
- 한 작업이 끝나면 짧게 보고하고 멈춘다. 대화가 길어졌으면 다음 작업은 새 대화에서 하자고 안내한다.
